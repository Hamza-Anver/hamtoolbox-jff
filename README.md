# HamToolbox
**I made this just for fun**

This is a collection of tools I've thrown together for my own use. All of these probably have better tools available somewhere, but I wanted to make my own. Accessible at [toolbox.hamzaanver.com](https://toolbox.hamzaanver.com)


## Tools
### [LaTeX to Image](https://toolbox.hamzaanver.com/tools/latex-to-image)
- Converts LaTeX to an image using the [katex](https://katex.org/) library. This is useful for generating images of equations for use in documents or presentations.

### [PDF N-up maker](https://toolbox.hamzaanver.com/tools/pdf-n-up-maker)
- Takes a PDF and creates a new PDF with multiple pages per sheet. I wanted some more features than regular n-up tools, so I made my own.

### [QR Code Maker](https://toolbox.hamzaanver.com/tools/qr-code-maker)
- What it says on the tin. Generates a QR code for a given URL/text/contact info. Has some visual customization options.

### [Image to PDF](https://toolbox.hamzaanver.com/tools/image-to-pdf)
- Puts an image onto an A4 or A3 page (portrait or landscape) with customizable margins, and gives a PDF. Supports just pasting the image, which was something I wanted.

### [Audio Visualizer](https://toolbox.hamzaanver.com/tools/audio-visualizer)
- Plays an audio file and draws its waveform and spectrogram using [wavesurfer.js](https://wavesurfer.xyz/). Can export as high resolution images.
